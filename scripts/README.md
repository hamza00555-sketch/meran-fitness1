# حزمة الصور — التوليد والنشر

الحزمة **الصور الكبيرة فقط**: صورة لكل جائزة، ولحظتَي الاحتفال (رفع المستوى
والرقم القياسي)، والحالات الفارغة، وأغلفة التقرير الشهري، وصور التخفيف، وصورة
ثابتة لكل تمرين، ومقطع متكرر للتمارين المتحركة. مجموعها اليوم ٢٠٧ فتحات.

الأيقونات الصغيرة في الواجهة — الترس، السلة، القلم، الأسهم — تبقى كما هي ولا
تدخل الحزمة إطلاقاً: تحويلها إلى صور مُنزَّلة يكلّف نطاقاً ولا يعطي شيئاً.

الصور تُولَّد عبر **Higgsfield**، وتُقصّ وتُحفظ في **`assets-cut/`** (في
الريبو — هو المصدر المعتمد)، ومنها **تُبنى الحزمة مع الموقع** في كل نشر ويصفها
ملف `manifest.json` واحد. التطبيق يقرأ المانيفست، ينزّل ما ينقصه، ويتحقق من كل
ملف قبل حفظه.

## دورة العمل

```bash
# ١. اطبع البرومبتات
npm run pack:prompts                 # أو: node scripts/prompts.mjs --json

# ٢. ولّد الصور عبر Higgsfield (GPT Image 2، 1k، high) واحفظ كل
#    واحدة باسم معرّفها: assets-src/ach_a1.png ...
#    أو أعد جلب المولَّد سابقاً:
node scripts/fetch-sources.mjs assets-src

# ٣. اقطع الخلفية البيضاء إلى شفافية حقيقية
node scripts/cut-white.mjs assets-src assets-cut   # الأغلفة تمر كما هي

# ٤. سجّل أصل كل صورة جديدة في scripts/pack-sources.json (الاختبار يفشل
#    لو نقص أصل أو زاد)، ثم:
npm run build                        # يبني الحزمة في dist/pack مع التطبيق

# ٥. ادفع إلى main — Vercel يبني وينشر الحزمة مع الموقع. لا مفاتيح ولا خطوة ثانية.
```

`assets-src/` (الأصول الخام) و`pack/` لا تدخلان الريبو؛ **`assets-cut/`
و`scripts/pack-sources.json` تدخلانه**. الأولى هي ما تُبنى منه الحزمة في كل
نشر، والثانية فيها النموذج ورابط الأصل لكل فتحة. الصور المصحّحة التي اعتمدها
حمزة (`"cut": "square-688"`) مقصوصة يدوياً بدقة أعلى من `cut-white.mjs`، فملفها
في `assets-cut/` هو المرجع، لا إعادة قصّ الأصل.

قائمة الفتحات مشتقّة من `src/assets/slots.js`، ومعرّفات الجوائز تأتي مباشرة من
`ACHIEVEMENTS` — فإضافة إنجاز جديد تضيف فتحته تلقائياً، بلا قائمة ثانية تُنسى.

## أين تُنشر: الموقع نفسه، على `/pack/`

`npm run build` هو `scripts/build.mjs`، وهو ما يشغّله Vercel في كل دفع:

1. التصميم الجديد ← `dist/`
2. التصميم القديم ← `dist/classic/`
3. الحزمة ← `dist/pack/` (`manifest.json` و`i/<sha>.webp|mp4`، والأساس `/pack/`)
4. فحوص تُفشل النشر بدل أن تنشر حزمة معطوبة: كل ملف في المانيفست موجود، لا PNG
   خام، لا ملف من الحزمة في الـprecache، والتصميمان يقرآن نفس المانيفست.

ويطبع حجم الحزمة وعدد ملفاتها والـprecache والوقت (~٢٠ ثانية للكل، منها ~٥
للحزمة على ٤ أنوية).

- **التصميمان يقرآن نفس المانيفست، `/pack/manifest.json`.** نفس الموقع ⇒ نفس
  مخزن الحزمة على الجوال، وكل تثبيت ينتهي بحذف كل ملف لا يذكره مانيفسته؛
  مانيفستان مختلفان يعنيان أن كل تبديل بين التصميمين يحذف صور الآخر. لذلك
  يُضبط الرابط **مرة واحدة** في البيئة التي يقرأها البناءان
  (`VITE_ASSETS_MANIFEST_URL`)، ثم يُقرأ من الحزمتين المبنيتين للتأكد. كود
  `classic/` لم يُلمس: رابط البَكِت القديم باقٍ فيه احتياطاً لا يُبلَغ أبداً
  (`"/pack/manifest.json"||"…r2.dev…"`).
- **الإصدار من المحتوى لا من الساعة**: تاريخ أحدث صورة (من رابط Higgsfield في
  `pack-sources.json`) + ٦ خانات من تجزئة المدخلات (بايتات كل مصدر، إطاره،
  وإعدادات الترميز)، مثل `2026.10.11-387eff`. نفس الصور ⇒ نفس الإصدار في كل
  نشر، فلا يعرض التطبيق «تحديثاً» لا يغيّر شيئاً؛ صورة تغيّرت أو انحذفت ⇒
  إصدار جديد. والتجزئة على المدخلات لا على WebP الناتج، فجهاز بناء يقرّب بكسلاً
  بشكل مختلف لا يغيّر الإصدار.
- **sharp إلزامي.** المصادر ~٥٠ ميغا PNG؛ بدونه يتوقف البناء بدل أن ينشرها خاماً.
  هو في `devDependencies` وملف القفل فيه نسخه الجاهزة لكل منصة، فـVercel يثبّته.
- **الكاش** (`vercel.json`): `/pack/i/*` سنة كاملة `immutable`، والمانيفست
  `no-cache`، وملف غير موجود تحت `/pack/` يرجع **404 حقيقي** لا صفحة التطبيق
  (وإلا هشّر المنزّل HTML إلى الأبد). وكلاهما `Access-Control-Allow-Origin: *`،
  فخادم `npm run dev` يقدر يقرأ حزمة الموقع المنشور (انظر `.env.example`).
- **الـservice worker** لا يضع الحزمة في الـprecache أبداً (`pack/**` في
  `globIgnores`) — ١٤ ميغا كانت ستُفرض على كل زائر. الصور الثابتة من
  `/pack/i/` `CacheFirst`، والمانيفست `NetworkFirst` حتى تجد الصور روابطها في
  النادي بلا شبكة.
- **الـservice worker الجذر كان يتوقف عند التشغيل** من أول كومت له حتى أكتوبر
  ٢٠٢٦: ملفات `public/assets` دخلت قائمة الـprecache مرتين (من `globPatterns`
  بلا revision ومن `includeAssets` بواحدة)، وWorkbox يرفض رابطاً واحداً بنسختين،
  فلم يُخزَّن شيء: التصميم الجديد لا يفتح بلا شبكة، وكل فتح يجلب الـJS (ومنه
  `medal3d`) والخطوط وصور الميداليات من الشبكة من جديد. الآن كل رابط مرة واحدة
  (٦٢ ملفاً، ٣٫١ ميغا بدل ١٢٫٧)، والبناء يفشل لو تكرر رابط أو دخل ملف من
  `public/` بلا revision (`scripts/precache.mjs`). و`cleanupOutdatedCaches`
  مطفأ في الجذر لأن تنظيف Workbox يحذف كل precache يحتوي اسمه على نطاق
  الـworker، و`https://host/` داخل اسم كاش التصميم القديم
  (`meran-classic-precache-v2-https://host/classic/`).

## لماذا اسم الملف هو التجزئة

كل ملف يُنشر باسم `i/<sha256>.webp` (أو `.mp4`). أربع نتائج:

- **التحديث رخيص.** التطبيق يقارن التجزئات؛ تغيّرت ٥ صور ⇒ ٥ ملفات.
- **الاستئناف مجاني.** «هل عندي هذه التجزئة محفوظة؟» هو كل شرط الاستكمال.
- **الصورة المشتركة تُنقل مرة واحدة.** فتحتان بنفس الصورة = نفس التجزئة = طلب
  واحد، ثم تُنشر على الفتحتين (مثل `ex_leg_curl` و`ex_lying_leg_curl`).
- **الكاش أبدي بأمان** (`immutable`) لأن الملف المتغيّر رابط مختلف.

المانيفست وحده بلا كاش — هو المؤشر الذي يجب أن يبقى طازجاً. ونشر Vercel ذرّي:
المانيفست والملفات التي يذكرها تظهر معاً، ونشر فاشل يترك الحزمة السابقة تعمل.

## R2 — اختياري الآن

كانت الحزمة تُنشر على البَكِت `meran-assets` في Cloudflare R2
(`https://pub-189be0412bdd4092aa44be319badfd91.r2.dev/manifest.json`، آخر
إصدار عليه `2026.08.30-1`). النشر هناك كان يحتاج مفاتيح لا تملكها إلا آلة
واحدة، فبقيت دفعة أكتوبر في الريبو ولم تصل الجوال. التطبيق لم يعد يحتاجه.

للنشر على بَكِت رغم ذلك: ابنِ بـ`--base` مطلق، انشر بـ`npm run pack:publish`
(`scripts/upload-r2.mjs`، جرّب `--dry` أولاً)، واضبط
`VITE_ASSETS_MANIFEST_URL` في بيئة البناء على Vercel — فيأخذه التصميمان معاً.
والبَكِت يحتاج CORS، لأن التطبيق يقرأ البايتات بـ`fetch` ليحسب التجزئة:

```json
[{
  "AllowedOrigins": ["https://<your-app>.vercel.app", "http://localhost:4173", "http://localhost:5173"],
  "AllowedMethods": ["GET", "HEAD"],
  "AllowedHeaders": ["*"],
  "ExposeHeaders": ["content-length", "etag"],
  "MaxAgeSeconds": 86400
}]
```

## لماذا خلفية بيضاء ثم قطع

إذا طلبتَ من GPT Image خلفية شفافة فإنه **يرسم** مربّعات الشطرنج التي تمثّل
الشفافية عادةً — بكسلات معتمة لا شفافية. طلب حقل أبيض مسطّح لا لبس فيه،
و`cut-white.mjs` يحوّله إلى ألفا حقيقية بتعبئة فيضية من الحافة للداخل: الأبيض
الذي يمكن الوصول إليه من الإطار فقط يُمسح، فاللمعة البيضاء داخل الشارة تبقى.

## الاختبار

- `node --test tests/assets.test.mjs` — المحرّك على وحدات ES الحقيقية.
- `node --test tests/pack-build.test.mjs` — يبني الحزمة الحقيقية من
  `assets-cut/` في مجلد مؤقت كما يفعل النشر، ويتحقق أن كل ملف في المانيفست
  موجود بالتجزئة والحجم الموعودين، وأن الإصدار ثابت لنفس الصور ويتحرك إذا
  تغيّرت، وأن Workbox بإعدادات التطبيق لا يأخذ أي ملف من الحزمة في الـprecache،
  وأن فحص الـprecache في البناء يرفض القائمة التي كانت توقف الـworker،
  وقواعد الـservice worker وترويسات `vercel.json`.
- `node tests/pack.e2e.mjs` — حقن أعطال: قطع الشبكة، ملف تالف، تحديث تفاضلي،
  حذف. يحتاج حزمتَي اختبار من `tests/make-test-pack.mjs` مبنيتين بـ`--base /pack/`
  (صور `public/assets` الموجودة أصلاً — صور حقيقية، لا شيء مرسوم للاختبار)،
  ويعترض `/pack/` في المعاينة بدل أن يقدّمها من `dist/pack`.
- `node tests/pack.live.mjs` — **الموقع المنشور فعلاً** (`LIVE=` لنشر آخر): بلا
  أي fixture، يتحقق من الترويسات والتجزئة والـ404 والتثبيت الكامل، ومن أن
  `sw.js` المنشور يذكر كل رابط مرة واحدة ولا ينظّف كاش التصميم القديم.
- `npm run test:pack-install` — التثبيت كما على الجوال: الإعدادات ← «حزمة
  الصور» ← تنزيل من `/pack/` في المعاينة بلا أي اعتراض، ثم الصورة المصحّحة على
  المسرح، والمقطع المتكرر من دفعة أكتوبر، والتصميم القديم (بالزر مضبوطاً عليه،
  وحزمته هي التي تعمل) لا ينزّل ولا يحذف شيئاً. ويتأكد أن الـservice worker
  يعمل فعلاً: الـprecache ممتلئ، وقاعدتا الحزمة أجابتا طلباً، والتطبيق يفتح بلا
  شبكة والصورة من الحزمة المنزّلة.
- `npm run test:offline` — الـworkerان معاً: الجذر يبدأ بلا خطأ ويخزّن
  `medal3d` والخطوط وصور الميداليات، والفتح الثاني يأتي منه لا من الشبكة،
  والتصميم الجديد يفتح ويُعاد تحميله بلا شبكة، و`/classic/` المثبّت قبله يبقى
  يفتح بلا شبكة بعد تفعيل الجذر. «بلا شبكة» هنا يُسقط الخادم نفسه
  (`tests/offline-origin.mjs`)، لأن `setOffline` في Playwright لا يوقف طلبات
  الـworker، فـworker فقد كاشه كان سيجلب من المعاينة وينجح الاختبار خطأً.
- `tests/deload.e2e.mjs` (القسم ١٢) يثبّت الحزمة من `/pack/` في المعاينة كما
  يقدّمها الموقع؛ بقية اختبارات المتصفح تحجب `/pack/` لترى البديل الثابت.

## تدقيق مكافأة الراحة

`npm run ledger -- <backup.json> [عدد الأيام] [--date YYYY-MM-DD]`

يطبع، يوماً بيوم، كيف وصل شريط الراحة الاختيارية إلى رقمه: التصنيف
(مؤهل/مدفوع/فائت)، وأثر كل يوم على الـstreak والتقدم والرصيد. الصفوف تأتي من
`computeRecovery` نفسها لا من حساب موازٍ، فلا يمكن أن يتفق التقرير مع نفسه
ويخالف ما يظهر في التطبيق.

نفس الجدول متاح داخل التطبيق: الإعدادات ← إدارة البيانات ← **سجل المكافأة
(تشخيص)**، مع زر لنسخه نصاً.

يحتاج ملف تصدير من إصدار `2.1` فما فوق — النسخ الأقدم لم تكن تحفظ إعدادات
الراحة (`restDays` والنمط)، ولا يمكن إعادة بناء السجل بدونها.

## أغلفة التقرير الشهري

اثنا عشر غلافاً، `cover_01` … `cover_12`، واحد لكل شهر ميلادي. تختلف عن بقية
الحزمة في ثلاثة أمور:

- **ليست مربّعة**: ١٠٢٤×٦٨٨، وهو مقاس ٣:٢ الذي يخرجه المولّد نفسه، فلا يُعاد
  تحجيمها ولا تفقد حدّتها. كل فتحة في `slots.js` تحمل `w` و`h` الآن، و
  `build-manifest.mjs` يقرأهما بدل `--size` العالمي.
- **كاملة الإطار**: لا خلفية بيضاء تُقتطع، فـ`cut-white.mjs` ينسخها كما هي بدل
  أن يمرّرها على التفريغ (الذي كان سيسحقها إلى مربّع ٥١٢).
- **بلا أشخاص وبلا نص**: معدّات وضوء فقط، مع مساحة خالية في الحافة السفلى يجلس
  عليها نص التقرير.

مجموعها ٠.٦٥ ميغا، فالحزمة صارت ٣.٧٩ ميغا بدل ٣.١٥. ومن نزّل الحزمة سابقاً
يجلب الأغلفة وحدها — العنونة بالمحتوى تجعل التحديث تفاضلياً.

# لقطات الشاشة ونظام التصميم

`design-system/` يصف النظام بالتوكنات والقواعد والدَّين. اللقطات هي نصفه
الآخر: القواعد تقول «الأكسنت دور لا لون»، واللقطتان — الرئيسية خضراء
والرئيسية جليدية — تُثبتان ذلك في صورة واحدة بلا كلام.

```bash
# ١. الحاصد: لقطة واحدة لكل شاشة، في حالة معلومة
npm run build && npm run screens

# ٢. ما الذي لا تغطّيه القائمة، وهل ذلك مقصود
npm run screens:audit

# ٣. الدفع إلى مسودة (المفتاح من .env لا من الكود)
npm run ds:push -- --dry              # الحمولة كاملة، بلا إرسال
MISWADAH_TOKEN=ms_live_… npm run ds:push       # التوكنات والمكوّنات والقواعد
MISWADAH_TOKEN=ms_live_… npm run ds:screens    # الصور، طلب لكل صورة

# ٤. القراءة والتحقق
MISWADAH_TOKEN=… npm run ds:push -- --current
MISWADAH_TOKEN=… npm run ds:screens -- --list
MISWADAH_TOKEN=… npm run ds:push -- --verify src/index.css src/pages/HomePage.jsx
```

النظام يُرفع في طلب واحد، والصور في طلب لكل واحدة إلى نقطة نهاية أخرى.
الصور تُحوَّل إلى WebP بعرض ١٢٠٠ في طريقها للخروج (السقف ٢٥٠KB لكل صورة،
و٤٠ صورة إجمالاً)، وكلها `kind: "capture"` — لقطات حقيقية من التطبيق وهو
يعمل. لا تُرسَل صورة مولَّدة على أنها لقطة أبداً؛ التمييز هو ما يخبر وكيلاً
لاحقاً أيّها دليل وأيّها فكرة.

الاسم يساوي معرّف الشاشة، فإعادة التشغيل تستبدل الصورة ولا تكرّرها.

المخرجات في `screenshots/` — **متجاهَلة في git**. الريبو يحفظ الحاصد لا
البكسلات، تماماً كما يفعل مع حزمة الفن.

## الملفان

| الملف | ما فيه |
|---|---|
| `screens.manifest.mjs` | **بيانات فقط**: الحالات المبدئية، وقائمة الشاشات وكيف تُبلَغ كل واحدة |
| `screens.mjs` | **آلية فقط**: الخادم، المتصفح، مفردات الخطوات، التحقق، الفهرس |

إضافة شاشة = كائن واحد في المانيفست. لا شيء غيره.

## ثلاثة أشياء تُوفّر عليك ساعة

**كل قيمة تُزرَع في التخزين تُكتب JSON.** `ls.get` في `src/utils.js` يمرّ كل
قيمة على `JSON.parse`. كتابة `hf_seen_version` كنص عارٍ `2.2` تعود رقماً لا
نصاً، فلا تساوي رقم النسخة أبداً، فتجلس نافذة «ما الجديد» فوق التطبيق
وتبتلع كل نقرة.

**كل حالة فيها تاريخ تزرع الإنجازات مفتوحة.** تاريخ طويل يفتح ~٢٠ إنجازاً
عند أول رسم، وكل واحد يستدعي `addXP`، فيعبر المستوى وتغطّي `LevelUpScreen`
الشاشة. تُزرع `hf_unlocked` بكل المعرّفات.

**التبويبات تُنقَر بالفهرس لا بالاسم.** «تمرين» جزء من «التمارين»، فمحدّد
بالاسم يختار الخطأ. الحاصد يستخدم `nav > button` بترتيب `NAV_TABS`.

## ما يضمنه الحاصد

لا يسلّمك صورة لا شيء. كل لقطة تُثبت أنها رُسمت قبل أن تُلتقط: نص بعينه على
الصفحة، والأكسنت الذي كان يجب أن يحلّه الوضع، وصفر أخطاء صفحة — ثم الصورة
نفسها لا بد أن يكون فيها تباين (`sharp().stats()`)، وإلا مرّت شاشة سوداء من
كل الفحوص السابقة.

والأنيميشن مُجمَّد في كل لقطة (`animations: 'disabled'`)، وإلا صوّرت نصف
نبضة توهّج.
